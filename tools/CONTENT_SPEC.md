# 授業データの書き方（js/data/*.js）

各ファイルは次の形です。

```js
BL.addLessons([
  {
    id: 'k1-1',                 // k=生物基礎, b=生物。「編-授業」の番号
    subj: 'kiso',               // 'kiso'（生物基礎）か 'bio'（生物）
    part: '第1編 生物の特徴',     // 編の名前（同じ編は同じ文字列）
    unit: '1-1',                // 表示用の番号
    title: '生物の多様性と共通性',
    lead: 'いろいろな生き物に共通する5つの特徴',   // 1行の説明
    sim: 'cell',                // 関係する「見る」の実験（下の一覧から。なければ書かない）
    slides: [                   // 授業の画面（4〜6枚）。1画面に1つのことだけ
      {
        h: 'こんなとき、どうなる？',   // 画面の見出し
        html: '<p>…</p>',            // 本文（HTML）。下の「使える書き方」
        ask: { q: '予想しよう：…？', c: ['正しい答え', 'まちがい1', 'まちがい2'], e: 'なぜ？の説明' }, // 任意：予想クイズ（c[0] が正解。表示時にまぜる）
        sim: 'cell',                 // 任意：右側にその実験を出す
        fig: '<svg …>…</svg>'        // 任意：右側に図（sim と fig はどちらか1つ）
      }
    ],
    exam: ['テスト・入試に出るポイント1', '…'],      // 2〜4個
    qs: [                       // 演習・確認テストの4択問題（ちょうど10問）
      { q: '問題文', c: ['正解', '誤り', '誤り', '誤り'], e: '解説（1〜2文）' }
    ],
    terms: [                    // 用語（ちょうど8個）。ゲームで使う
      { w: 'ミトコンドリア', d: '呼吸を行い ATP をつくる細胞小器官' }
    ]
  }
]);
```

## ルール

- **c[0] がいつも正解**（表示するときにまぜる）。選択肢は4つ、どれも同じくらいの長さ・形にする。「上のすべて」「どれでもない」は使わない（まぜると意味が変わるため）。
- 対象は高校生。**やさしい日本語**で、むずかしい言葉は最初に出たとき（ ）でかみくだく。内容は現行の教科書（2022年からの学習指導要領）に合わせ、まちがいがないこと。
- 1つ目の画面は「こんなとき、どうなる？」型の導入（身近な例＋ ask の予想クイズ）。最後の画面は「まとめ」。
- `terms` の d は 30 字くらいまで。w は d の中に出さない。
- 文字列は 'シングルクォート'。中に ' を使わない。HTML の属性は "ダブルクォート"。
- ファイルは `node tools/check.js` でエラーが出ないこと。

## 本文で使える書き方（html）

- `<p>…</p>`、`<ul><li>…</li></ul>`、`<ol>…</ol>`
- `<b class="key">重要語</b>`：太字・色つき（重要語は必ずこれ）
- `<div class="box">…</div>`：囲み（公式・きまり）
- `<div class="tip">…</div>`：かみくだいた説明・覚え方
- `<table class="tbl"><tr><th>…</th></tr><tr><td>…</td></tr></table>`：比べる表
- 化学式は `CO<sub>2</sub>`、`H<sub>2</sub>O`。

## fig（図）の書き方

- `<svg viewBox="0 0 400 300" ...>` で、幅・高さの属性は書かない。
- 色は CSS 変数で：`fill="var(--panel)"` `stroke="var(--ink)"` `fill="var(--accent)"`（緑） `fill="var(--warm)"`（オレンジ） `fill="var(--ask)"`（青） `fill="var(--chip)"`（うすい灰）。`<text>` は `fill="var(--ink)"` `font-size="14"`。
- 図はかんたんで正確なもの（矢印のつながり図・表のかわりの図など）。むりに絵をかかなくてよい。

## sim に書ける名前（「見る」の実験）

| 名前 | 内容 |
|---|---|
| scale | 大きさくらべ（原子〜ヒト。ズームで大きさの違いを見る。顕微鏡で見える範囲つき） |
| cell | 細胞の構造（動物・植物・原核。小器官をクリックすると拡大図） |
| enzyme | 酵素のはたらき（温度・pH・基質濃度と反応速度） |
| photo | 光合成と呼吸（光の強さと CO2 吸収速度、陽生・陰生植物、補償点・光飽和点） |
| dna | DNA からタンパク質へ（相補的な塩基・転写・翻訳・コドン表・突然変異） |
| mitosis | 細胞周期・体細胞分裂と減数分裂（DNA量のグラフ） |
| sugar | 血糖値の調節（食事・運動、インスリン・グルカゴン、糖尿病） |
| immune | 免疫（一次応答・二次応答、ワクチン） |
| neuron | ニューロンと活動電位（閾値・全か無かの法則） |
| succession | 植生の遷移（裸地→陰樹林、林床の明るさ） |
| biome | バイオーム（年平均気温と年降水量） |
| mendel | 遺伝の交配（一遺伝子雑種・二遺伝子雑種・分離比） |
| popgen | 集団の遺伝（遺伝子頻度・自然選択・遺伝的浮動） |
| predator | 個体群（ロジスティック成長・被食者と捕食者） |

## 図（fig）を教科書レベルにするためのきまり

- **1画面に1枚**。説明の画面にはできるだけ図をつける（文字だけの画面をなくす）。「まとめ」には全体のつながり図（矢印・表のような図）を。
- `viewBox="0 0 480 360"`（横長がよいときは `0 0 520 340` でもよい）。width/height 属性は書かない。
- **ラベル（名前）を必ずつける**：引き出し線（`<line>` 1px ＋ 先に小さな点）＋ `font-size="14"`〜`15` の文字。文字が線や図と重ならないように。
- **形は本物に近く**：細胞小器官・器官・生物は教科書の模式図のような形で（ミトコンドリアは二重膜とクリステ、葉緑体はチラコイドとグラナ、ニューロンは細胞体・樹状突起・軸索・髄鞘、心臓は4つの部屋と弁 など）。四角い箱を矢印でつなぐだけの図は「流れ」を表すときだけ。
- **大きさがある物には大きさを書く**：スケールバー（例：`|——| 10 μm`）や「約 ○○ μm」。大きさをくらべる図は、同じ縮尺で並べる（ちがいすぎるときは「×1000 拡大」のように枠で拡大を示す）。
- **グラフ**は軸・目盛り・単位・軸の名前を書く。
- 色（明るい画面・暗い画面の両方で見えるように、CSS 変数を使う）：
  - 線・文字 `var(--ink)`、うすい文字 `var(--muted)`、背景の面 `var(--panel)`・`var(--chip)`
  - 強調 `var(--accent)`（緑）・`var(--warm)`（オレンジ）・`var(--ask)`（青）・`var(--c1)`赤 `var(--c3)`青 `var(--c5)`黄土 `var(--c6)`紫
  - 生物の色：細胞質 `var(--cyto)`、核 `var(--nuc)`、葉 `var(--leaf)`・`var(--leaf2)`、土 `var(--soil)`、空 `var(--sky)`、水 `var(--water)`
  - 細胞膜は `#c9a227`、ミトコンドリアは `#f3b38a`（ふち `#a0522d`）、葉緑体 `#7fbf68`（ふち `#2f6b3a`）のように固定色を使ってもよい（暗い画面でも見える明るさで）。
- `<marker>` を使うときは id を図ごとに変える（例 `id="k12a"`）。
- できたら `node tools/figshot.js <授業id> <フォルダ>` で PNG にして、**画像を目で見て**確かめる（文字の重なり・はみ出し・暗い画面での見え方）。
