# 生物ラボ

高校の **生物基礎・生物** を、**動かして見る・授業・演習・ゲーム** で学べる Webアプリです。
`index.html` をブラウザ（Chrome / Edge / Safari）で開くだけで動きます（インストール不要）。

見た目と画面の構成は「分子ラボ3D」「物理ラボ3D」「英検ラボ」とそろえた、方眼ノート風のデザインです。

**公開ページ（GitHub Pages を有効にした場合）**: https://nakatadaiki1012-design.github.io/biology-learning/

> フォントはインターネットから読み込みます（つながっていなくても、ふつうの字体で動きます）。

## 画面の構成

最初に開くのは **ホーム**（4つの大きなボタン・進み具合・「続きから」・☀️今日の1問）。左上の「生物ラボ」でいつでもホームへもどれます。
画面上は **見る／授業／演習／ゲーム** の4つだけ。右上のボタンで明るい画面・暗い画面を切りかえられます。

**スマホでもページをスクロールせずに使える**ように作っています。

- 見る：上で実験をえらび（1行）、まん中に図、下に操作パネル。
- 授業：「📖 説明／🔬 実験（🖼 図）」を上のボタンで切りかえ。左右にスワイプしても前後に進めます。
- 授業の一覧：編ごとにたためます（進み具合のバーつき）。
- 演習：設定 → スタートで問題だけの画面になり、「✕」で設定へもどります。
- 答えると大きな ◯ ／ ✕ が出て、連続正解すると 🔥、結果は ★ 3つで表示されます。
- **答えたあとに「📊 図で確かめる」**：4択は、その問題に合う授業の図（自動でえらぶ）と「📖 この授業の画面を開く」ボタン。計算問題は、**その問題の数字でかいた図**（帯グラフ・円グラフ・パネットの四角・目盛りなど）。授業の予想クイズも、答えると解説の図が出ます。

### 授業（生物基礎 19・生物 21 の授業）

教科書（学習指導要領）の順に並んでいます。大きな文字で **1画面ずつ** 進みます（「次へ」ボタン、キーボードの ← →）。

1. **こんなとき、どうなる？**：身近な例から予想クイズ（3択）。答えると「なぜ？」が出る
2. **説明の画面**：**すべての画面に図**（全 236 画面）。教科書のような模式図にラベル（引き出し線）つき、大きさのある物にはスケールバーや同じ縮尺での比較。「見る」の実験がそのまま出る画面もある
3. **まとめ**
4. **テスト・入試に出るポイント** と、その授業の用語の一覧
5. **確認テスト**：4問。3問以上正解で「合格」のはんこ。合格すると「次の授業 →」

見た授業には ✓、合格した授業には はんこがつきます。「続きから」で次の授業を始められます。

### 演習

- **4択**：全 400 問（各授業 10 問）。単元をえらんで 10・20・40 問。答えると解説
- **計算**：14 種類（シャルガフ・細胞周期・ミクロメーター・濃縮率・光合成速度・組換え価・ハーディ・ワインベルグ・呼吸商・PCR・伝導速度・標識再捕法・成長量・エネルギー効率など）。**数字は毎回変わる**。「ヒント」で解き方を1行ずつ
- **復習**：まちがえた問題がたまり、正解すると消える

### 🏆 クラス対戦（ゲーム → いちばん上のカード）

先生の大画面（プロジェクター）で部屋をつくり、生徒はスマホで 4 けたの番号（または QR コード）から参加します。名前はニックネームで OK。

| あそびかた | 内容 |
|---|---|
| 🎯 クイズ大会 | 先生ペースの 4 択（▲◆●■ の 4 色）。早く正解するほど高得点（最大 1000 点）。全員が答えるか時間切れで、**答え・みんなの回答の分布・解説と図**を大画面に。そのあとランキング → 次の問題。最後に表彰台 |
| 🚀 タイムアタック対戦 | 全員同じ順番の問題を、決めた時間（1〜5 分）でどんどん解く。連続正解でボーナス、まちがえると 1.5 秒ストップ。大画面のランキングがリアルタイムで動く |

- 設定：科目（生物基礎・生物・両方）、範囲（編をえらぶ）、問題の数・1 問の時間、ランキングに出す人数。
- 「同じメンバーでもう一度」で、点数だけリセットして続けられます。
- データベースは英検ラボ・論理表現ラボと同じ Firebase（`js/config.js`）。部屋は `rooms/b＋4けた` なので、ほかのアプリとぶつかりません。
